### 사례 / Case

> 어떤 팀의 수용 기준: "WHEN 사용자가 검색어를 입력하면 THE 시스템은 SHALL 3초 이내에 결과를 표시한다." 구현 결과 검색 결과는 색상으로만 구분되고 키보드로는 조작할 수 없다. 명세를 위반한 것은 아니다.
>
> *A team's acceptance criterion says results appear within 3 seconds. The result is distinguished only by colour and cannot be operated by keyboard — yet the spec was not violated.*

**질문 1. 명세는 무엇을 빠뜨렸는가? / What did the spec leave out?**

**질문 2. 이런 누락을 줄이려면 무엇을 해야 하는가? / How can such omissions be reduced?**
